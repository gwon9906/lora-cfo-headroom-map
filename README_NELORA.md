# NELoRa 재검증 — 보고된 신경망 이득은 어디로 갔는가

> *NELoRa 원본 캡처에서 검출기들을 같은 심볼에 비교했다. **NELoRa 파이프라인은
> de-chirp 이전의 데시메이션 단계를 건너뛰고, 그 때문에 3.5~3.9 dB 를 잃는다.**
> 데시메이션을 제대로 넣은 표준 수신기는 정합필터와 0.2 dB 이내로 붙는다.*
>
> 측정일 2026-09-21 · 대상 [10] NELoRa (SenSys'21) · 본편 README §7.3 의 후속
>
> ⚠️ **개정판이다.** 초판(커밋 `68b5ce4`)의 §4·§6 은 틀렸다. 내 chirp 생성기에
> 버그가 있었고, "표준 수신기" 라고 부른 것이 표준 수신기가 아니었다.
> 무엇이 어떻게 틀렸고 어디까지 살아남았는지는 **§9 정정 기록** 에 있다.
>
> ⚠️ SNR 축은 **합성 AWGN** 이다. 받은 릴리스에 SNR 라벨이 없어 캡처에 잡음을 더해
> 만들었고, 캡처 자체가 이미 잡음을 포함하므로 실제 SNR 은 표기값보다 약간 낮다.
> 절대 dB 가 아니라 **같은 축 위에서의 검출기 간 격차**만 읽어야 한다.
>
> ⚠️ 논문이 보고한 신경망 이득과의 **직접 비교는 하지 않았다**. 축이 다르다(§8-4).

## 0. 요약

| 주장 | 결과 |
|---|---|
| **NELoRa 는 데시메이션을 건너뛰어 손해를 본다** | **확정.** D1 → 표준 수신기 = **+3.45 ~ +3.91 dB** (SF7~10, 95% CI 모두 0 배제) |
| 데시메이션한 de-chirp+FFT 는 정합필터와 등가 | **확인.** 표준 수신기 − D2 = **+0.06 ~ +0.16 dB** (이상 신호에서도 0.25 dB) |
| D2→D3 = "하드웨어 파형 부정합" | **기각.** **+0.11 dB** [+0.05, +0.20] — 0 은 아니나 실질적으로 없다 |
| 5.9% SER 바닥 | 잡음도 라벨 오염도 아님. **−1 bin 동기 오차**, 패킷 단위 집중 |
| ~~비동기 alias 결합 계열이 근본적으로 뒤진다~~ | **철회.** 결합 방식이 아니라 **데시메이션 생략** 이 원인 (§9) |

한 줄 요약:

> **NELoRa 파이프라인은 de-chirp 전에 심볼당 N 샘플로 내리지 않아 3.5~3.9 dB 를
> 잃는다. 그 단계를 넣으면 고전 수신기가 정합필터 성능에 도달한다.**

## 1. 데이터셋 — 받은 것은 SNR 릴리스가 아니다

| 항목 | 실제 |
|---|---|
| 파일 형식 | MAT 컨테이너 아님. **헤더 없는 interleaved float32 (complex64)** |
| 경로 | `<SF>/<packet>/{symbol_idx}_{code_label}_{packet_id}_{sf}.mat` |
| 4번째 필드 | **패킷 ID** (184개 값 × 각 78회, 디렉터리명과 중복 — 새 정보 없음) |
| 표본화 | fs = 1 MHz, BW = 125 kHz, **OSF = 8** (전 SF 공통) |
| SNR 필드 | **없음** |
| 빠진 심볼 | `symbol_idx` **10, 11** — SFD 다운چ프 자리 (§6 에서 결정적) |

`code_label` 이 재래식 디코더 출력일 가능성(그렇다면 D1 이 자기가 만든 정답을 맞히는
셈이 되어 비교가 기울어진다)을 검증했고 **기각**했다:

- preamble(`symbol_idx` 0~7)의 `code_label` 이 **99.8%** 가 0 — 프로토콜 구조와 일치
- D1 과 D2 의 예측이 갈린 22개 심볼에서 라벨이 D1 쪽 50.0%, D2 쪽 4.5%,
  **둘 다 아님 45.5%** — 라벨이 D1 계열 출력이면 나올 수 없는 분포

## 2. 방법

| | 정의 |
|---|---|
| **D1** | NELoRa baseline. OSF=8 에서 de-chirp → M-FFT → `abs(cut1)+abs(cut2)` → argmax |
| **표준 RX** | 교과서 LoRa 수신기. **브릭월 LPF(±BW/2) → N 샘플 데시메이션 → de-chirp → N-FFT** |
| **D2** | 이상적 MF. 해석적 chirp 뱅크와의 비동기 상관 (OSF=8 전대역) |
| **D3** | 경험적 MF. 실제 캡처에서 추정한 코드별 파형 프로토타입과의 상관 |

**D1 과 표준 RX 의 차이는 결합 방식이 아니라 순서다.** D1 은 OSF=8 상태에서 de-chirp
한 뒤 스펙트럼 조각을 합치고, 표준 RX 는 de-chirp *이전에* 대역을 거르고 내린다.
그 순서가 두 가지를 바꾼다: 대역 밖 잡음 7/8 을 버리고, 두 alias 조각이 같은 빈에
**코히런트하게** 접힌다.

설계상 지킨 것:

1. **SNR 축은 합성** — NELoRa 자신이 데이터셋을 만드는 방식(캡처 + AWGN)을 따랐다.
2. **프로토타입 패킷과 평가 패킷을 완전히 분리** — 같은 캡처로 프로토타입을 만들고
   그 캡처를 평가하면 D3 이 자기 잡음 실현을 알아본다.
3. **모든 팔에 같은 정렬을 건다** — 신호 쪽에 (τ, ε) 보정을 걸고, 기준은 전부 미정렬.
4. **CI 는 패킷 단위 부트스트랩** (1000 복제). 잡음 실현은 고정이므로 CI 는 패킷·심볼
   표집 변동만 반영한다.

## 3. 5.9% SER 바닥의 정체

무잡음 원본, 평가 123패킷 / 8364심볼, 올바른 생성기 + 전역 정렬 적용.

**검출기들은 서로 동의하는데 라벨과만 어긋난다.**

| | 심볼 수 | 비율 |
|---|---|---|
| 하나라도 틀림 | 494 | 5.91% |
| **셋 다 틀림** | **490** | 5.86% (틀린 것의 **99.2%**) |
| 셋 다 틀리고 **예측까지 일치** | 483 | 셋 다 틀린 것의 **98.6%** |

**오류는 −1 bin 한 방향이다.**

| 검출기 | \|예측−라벨\| ≤ 1 | 상위 오프셋 |
|---|---|---|
| D1 | **99.8%** | −1: 477 |
| 표준 RX | 94.7% | **−1: 465**, −16: 2, +46: 2 |
| D2 | 94.9% | **−1: 465** |
| D3 | 94.3% | −1: 464 |

**+1 은 없다.** 잡음이 원인이면 대칭이어야 한다.

**패킷 단위로 집중된다.** 상위 10% 패킷(12개)이 전체 오류의 **55.9%**, 오류율 50%
넘는 패킷이 **4/123** (`84`, `142`, `147`, `177`).

> **바닥은 데이터 문제도 검출기 문제도 아니고 동기 문제다.**

## 4. 전역 오프셋

경험적 프로토타입과 이상적 chirp 의 상관이 낮은 것이 하드웨어 왜곡인지 동기 오차인지를
(타이밍 τ, CFO ε) 2D 탐색으로 가른다.

| SF | τ (샘플) | ε (bin) | \|상관\| 정렬 전 → 후 |
|---|---|---|---|
| 7 | +1.00 | +0.1562 | 0.932 → **0.989** |
| 8 | +1.00 | +0.1250 | — |
| 9 | +0.75 | +0.1250 | — |
| 10 | +0.75 | +0.1250 | — |

τ 는 1 샘플 이하(= 1/8 bin 이하), ε 는 1/8 bin 안팎으로 **네 SF 에서 거의 같다.**
코드마다 제각각이면 하드웨어 왜곡이지만, 하나의 상수면 캡처·추출 체인의 고정 오프셋이다.

> ⚠️ 초판은 이 값을 τ=+2.00, ε=+0.188, 정렬 전 상관 0.83 으로 적었다. 그중
> **τ −1.00 / ε −0.0625 는 데이터가 아니라 내 chirp 생성기의 오차**였다 (§9-1).
> 결론(상수 오프셋 하나로 설명된다)은 유지되지만 숫자는 위 표가 맞다.

## 5. 검출기 비교 — SF7 심화

평가 123패킷 / 4000심볼. 10% SER 도달 SNR, 패킷 부트스트랩 1000 복제.

| 검출기 | 10% SER | 95% CI |
|---|---|---|
| D1 NELoRa abs-alias (2블록) | −14.22 dB | [−14.80, −12.50] |
| D1 2블록 복소합 | −15.92 dB | [−16.23, −14.69] |
| **표준 RX (LPF→데시→dechirp)** | **−18.49 dB** | [−18.84, −18.01] |
| 표준 RX (LPF 없이 솎기만) | −10.04 dB | [−10.26, −8.86] |
| D2 이상적 MF | −18.59 dB | [−18.97, −18.07] |
| D3 경험적 MF | −18.71 dB | [−19.13, −18.14] |

**격차** (복제별 차이의 95% CI — 같은 심볼·같은 잡음에 대한 대응비교):

| 격차 | 값 | 95% CI | |
|---|---|---|---|
| D1 → 표준 RX | **+4.28 dB** | [+3.98, +5.40] | 유의 |
| 표준 RX → D2 | **+0.11 dB** | [+0.06, +0.21] | 등가 |
| D1 → D2 | +4.39 dB | [+4.10, +5.63] | 유의 |
| **D2 → D3** | **+0.11 dB** | [+0.05, +0.20] | 0 은 아니나 실질적으로 없다 |

**D2→D3 에 대하여:** CI 가 0 을 배제하므로 "구별되지 않는다" 고는 못 쓴다. 그러나
크기가 0.11 dB 다. 초판의 "하드웨어 파형 몫은 존재하지 않는다" 는 CI 없이 null 을
주장한 것이므로 철회하고, **"0.11 dB [+0.05, +0.20] — 통계적으로는 0 이 아니지만
크기가 무시할 수준"** 으로 쓴다.

**LPF 없이 솎기만 하면 −10.04 dB** 로 급락한다. 안티앨리어싱 없이 8배 솎으면
1 MHz 대역의 잡음이 125 kHz 안으로 접혀 들어오기 때문이다. 데시메이션은
**거르고 나서** 해야 한다.

## 6. 표준 수신기가 정말 표준인가 — 이상 신호 온전성 검사

실데이터를 논하기 전에, 이상 신호(타이밍·CFO = 0)에서 표준 RX 가 MF 와 붙는지부터
확인했다. 안 붙으면 내 구현이 틀린 것이다.

| 검출기 | 10% SER |
|---|---|
| MF (OSF=8 전대역 상관) | **−20.00 dB** |
| **표준 RX (LPF→데시→dechirp)** | **−19.75 dB** |
| 표준 RX (LPF 없이 솎기만) | −10.75 dB |
| NELoRa abs-alias (2블록) | −16.14 dB |

**0.25 dB 이내로 붙는다.** 데시메이션된 de-chirp+FFT 가 정합필터와 등가라는 LoRa
문헌의 상식이 재현된다. 실데이터에서도 네 SF 모두 +0.06~+0.16 dB (§7).

### 결합 방식은 부차적이다

| 결합 | 10% SER |
|---|---|
| 2블록 abs (NELoRa 원본) | −16.14 dB |
| 2블록 복소합 | −16.77 dB |
| 2블록 전력합 | −16.48 dB |
| 8블록 abs | −12.29 dB |
| 8블록 복소합 | −10.75 dB |
| **표준 RX** | **−19.75 dB** |

2블록에서는 복소합이 abs 보다 0.63 dB **좋고**, 8블록에서는 1.5 dB **나쁘다**.
방향이 블록 수에 따라 뒤집히므로 "복소합이 옳다/그르다" 는 단정은 성립하지 않는다.
어느 쪽이든 표준 RX 와는 3~9 dB 차이라 **결합 방식은 부차적 변수**다.

> 교차검증: `8블록 복소합 = −10.75 dB` 와 `LPF 없이 솎기만 = −10.75 dB` 가 정확히
> 일치한다. M-FFT 전 블록의 복소합은 시간영역 8배 솎기와 같은 연산이므로 당연하다.
> 두 경로가 독립적으로 같은 값을 내놓는 것은 구현이 맞다는 방증이다.

### C2 가 실패한 이유 — preamble 만으로는 안 된다

패킷별 preamble 로 (τ, ε) 를 추정하는 팔은 실패했다. 선형 chirp 은 **delay-Doppler
결합** 때문에 τ 이동과 ε 이동이 거의 같은 효과를 낸다. preamble 은 전부 code 0 이므로
2D 지표가 **능선** 이 된다:

- 최대값의 99% 이상인 (τ, ε) 점이 **65 / 2145 개**
- 능선 기울기 **+0.1250 bin/샘플 = 정확히 1/OSF** (이론값과 일치)

실제 수신기는 SFD **다운چ프** 로 이 축퇴를 깨는데, 이 데이터셋은 `symbol_idx`
**10, 11 을 빼놨다**. 128개 코드를 쓰는 전역 정렬은 코드마다 순환이동이 달라 축퇴가
깨지므로 잘 동작한다.

### 통째로 밀린 패킷 — CFO 가 아니라 추출 정렬

프로토타입 뱅크를 정수 bin (= OSF = 8 샘플) 만큼 밀어가며 본 오류율:

| 패킷 | −1 bin | **+0 bin** | **+1 bin** | +2 bin |
|---|---|---|---|---|
| 147 | 100.0% | 83.8% | **16.2%** | 100.0% |
| 84 | 100.0% | 79.4% | **20.6%** | 100.0% |
| 177 | 100.0% | 57.4% | **42.6%** | 100.0% |

**심볼 추출 창이 정수 bin 만큼 밀려 잘린 것**이다. 123개 중 4개 = 3.3%.
CFO 보상으로 고칠 수 있는 종류가 아니며 데이터셋 정렬 결함이다.

## 7. SF7/8/9/10

올바른 생성기, 패킷 부트스트랩 400 복제 중앙값. SF 마다 SNR 격자를 3 dB 씩 내렸다.

| SF | τ | ε | D1 | **표준 RX** | D2 | **D1→표준 RX (95% CI)** | 표준 RX−D2 |
|---|---|---|---|---|---|---|---|
| 7 | +1.00 | +0.156 | −14.61 | **−18.50** | −18.63 | **+3.91** [+3.64, +4.75] | +0.13 |
| 8 | +1.00 | +0.125 | −18.71 | **−22.18** | −22.34 | **+3.45** [+3.14, +3.72] | +0.16 |
| 9 | +0.75 | +0.125 | −21.29 | **−24.83** | −24.89 | **+3.53** [+3.24, +3.78] | +0.06 |
| 10 | +0.75 | +0.125 | −24.15 | **−27.59** | −27.67 | **+3.45** [+3.21, +3.70] | +0.07 |

> **네 SF 모두에서 D1 → 표준 RX 격차의 CI 가 0 을 배제하고, 표준 RX 는 D2 와
> 0.2 dB 이내로 붙는다.**

SF7 이 §5 와 §7 에서 다른 이유: §5 는 n=4000 / 부트스트랩 1000, §7 은 n=2500 / 400.
D1→표준RX 가 +4.28 vs +3.91 로 **0.37 dB** 차이 난다. 표본 크기에 따른 흔들림의 크기가
이 정도이므로, 헤드라인은 **3.5~3.9 dB** 범위로 쓰는 것이 안전하다.

### 함정 하나 — "교차 없음" 은 바닥이 높다는 뜻이 아니었다

고정 SNR 격자(0 ~ −20 dB)로 돌렸을 때 SF8/9/10 이 "교차 없음"으로 나왔는데, 바닥이
높아서가 아니라 **격자가 얕아서**였다. 무잡음 오류율은 SF8 **0.00%**, SF9 **0.00%**,
SF10 4.17% (밀린 패킷 1개 포함) 다.

## 8. 한계

1. **SNR 축이 합성이다.** 절대 dB 를 인용하지 말고 격차만 쓸 것.
2. **CI 는 패킷 표집 변동만 반영한다.** 잡음 실현을 고정한 대응비교이므로, 잡음까지
   재추출하면 구간이 넓어진다. §5 의 격차 CI 가 좁은 것은 그 때문이다.
3. **D3 은 SF7 에서만 성립한다.** N = 2^SF 는 커지는데 캡처 수는 그대로여서 SF8/9/10
   코드 커버리지가 21% / 11% / 9% 다. §7 표에서 D3 을 뺀 이유다.
4. **논문의 신경망 이득과 직접 비교하지 않았다.** NELoRa 의 DNN 경로를 돌리지 않았고,
   보고된 1.84~2.35 dB 는 이 실험과 축(데이터 분할·SNR 정의·평가 지표)이 다르다.
   **같은 축에서 신경망까지 돌리는 별도 실험이 필요하다.**
5. **SFD 가 없어** 실제 수신기의 동기 경로를 그대로 재현할 수 없었다.
6. 표준 RX 의 브릭월 LPF 는 이상적 필터다. 실제 수신기의 유한 길이 필터는 이보다
   조금 나쁘다. 즉 **+3.5 dB 는 상한에 가까운 추정**이다.

## 9. 정정 기록

초판(커밋 `68b5ce4`)에서 틀린 것과 그 파급.

### 9-1. chirp 생성기 — §4 의 숫자가 바뀌었다

`nelora_mf_test.ideal_chirps` 는 순시주파수를 `cumsum` 으로 적분해 위상을 만든다.
이산화 오차가 샘플율에 의존하므로:

| 성질 | cumsum 판 | 해석적 판 (`nelora_chirp`) |
|---|---|---|
| `X[c]` vs `roll(X[0], −OSF·c)` 최대오차 | **2.000** | **0.000** |
| OSF=8 판 데시메이션 vs OSF=1 판 \|상관\| | **0.714** | **1.000** (오차 0) |

두 생성기는 정확히 **(τ = −1.00 샘플, ε = −0.0625 bin)** 어긋나 있고, 그만큼 보정하면
\|상관\| 이 **1.0000** 이 된다. 따라서 초판의 τ=+2.00 / ε=+0.188 중 그 몫은 데이터가
아니라 내 생성기였다. 올바른 값은 §4 표.

정렬 전 프로토타입 상관도 **0.83 → 0.932** 로 바뀐다(초판의 0.83 은 생성기 불일치가
섞인 값). 정렬 후 0.989 는 동일.

`ideal_chirps` 에 사용 금지 주석을 달았고, 재현을 위해 함수는 남겨 뒀다.

### 9-2. §6 의 "표준 수신기" 는 표준 수신기가 아니었다

초판 `d1_decimate` 는 **de-chirp 를 먼저 하고** 대역을 잘랐다. de-chirp 후의 톤은
±BW 에 걸쳐 있으므로 ±BW/2 로 자르면 신호를 자르는 짓이다. 그래서 "브릭월
데시메이션판도 abs-alias 와 −0.04 dB 차이" 라는 결과가 나왔고, 거기서

> ~~"최선의 D1 변형도 D2 와 3.6 dB 차이가 끝까지 남는다. 구현 선택의 손실이 아니라
> 비동기 alias 결합 자체의 손실이다."~~

라는 **넓은 결론**을 썼다. **이 문장은 철회한다.** 순서를 바로잡으면 표준 RX 는 MF 와
0.25 dB 이내로 붙는다(§6). 남는 것은 좁고 참인 서술이다:

> **NELoRa 구현은 데시메이션 단계를 건너뛰었고, 그 결과 3.5~3.9 dB 를 잃는다.**

초판이 "OSF=1 데시메이션 −7.77 dB" 를 관측하고도 넓은 결론으로 간 것이 오류다.
그 −7.77 dB 자체가 LPF 누락의 신호였는데 변형 실패로만 읽었다.

### 9-3. 증거로 쓰지 않은 것

- **U = 2, 4 업샘플 변형** (−7.87 / −11.66 dB): 폴딩 인덱스 매핑이 깨져 나온 값이라
  초판부터 표에서 제외했다. 유지.
- **"저자들이 올바른 버전(`chirp_comp_alias`)을 주석 처리했다"** 는 프레임: 근거 없다.
  복소합의 우열이 블록 수에 따라 뒤집히므로(§6) 어느 쪽도 "올바른 버전" 이 아니다.
  어떤 글에도 넣지 말 것.

### 9-4. 살아남은 것

§1(라벨 출처 기각), §3(바닥의 정체), §6 의 축퇴·밀린 패킷, D2→D3 이 실질적으로 0 이라는
결론은 모두 유지된다. §3 은 올바른 생성기에서 **더 강해졌다**: 검출기 간 오류 겹침
96.2% → **99.2%**, 예측 일치 97.2% → **98.6%**.

## 본편 README 와의 관계

§7.3 은 NELoRa 의 1.84~2.35 dB 를 "설명해야 할 기정사실" 로 두고, 그 원인이 denoising
이 아니라 임페어먼트 보상일 것이라는 가설을 세웠다. 이 재검증은 §7.3 이 열어두지 않았던
갈래에 무게를 싣는다 — **보고된 이득과 같은 크기의 몫이 고전 수신기의 데시메이션 단계
하나로 회수된다.** 다만 §8-4 때문에 아직 "이득이 재현되지 않는다" 고는 쓸 수 없다.

§4.2 의 AWGN 심볼 단위 정리는 이 결과에 의존하지 않으므로 그대로 유효하다.

이것은 출판된 철회가 아니라 한 데이터셋 릴리스에서의 측정이다. 어떤 글에서도
**열린 질문**으로 쓰고, 단정이나 비난으로 쓰지 말 것.
