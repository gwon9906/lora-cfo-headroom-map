# LoRa CFO Headroom Map

> *초저 SNR LoRa 에서 고전 CFO 추정이 어디서 멈추는가 — 계산 가능한 상한과 함께.*
> (저장소는 Complex-valued BAM 기반 신호 복원 시도에서 출발했다. `01`–`07` 폴더가
> 그 궤적을 보존한다. BAM 결과 자체는 §3.2 에서 철회됐다.)

> **초저 SNR LoRa 복조 성공률을 올리기 위해 Complex-valued BAM 기반 신호 복원을 시도했고, 재검증 끝에 실제 개선 요인이 검출기에 있음을 찾아 -25 dB 성공률을 13.0% → 52.6% 로 끌어올린 연구. 동시에 1차 결과와 1차 결론을 스스로 반증하고, 학습이 의미를 갖는 조건이 어디까지 좁아지는지(저차 모델로 기술되지 않는 시변 CFO · sequence-level)를 계산 가능한 상한 및 신뢰구간과 함께 정량화했다.**

## 1. 문제 정의

- LoRa는 CSS(Chirp Spread Spectrum) 기반 변조로, de-chirp + FFT argmax로 심볼을 복조한다.
- **초저 SNR(-25 ~ -30 dB) 구간에서는 이 기존 복조 파이프라인이 무너진다.**
- 본 연구의 **당초** 목표는 **신경망 기반 신호 복원(denoising)** 을 앞단에 붙여 복조 가능한 SNR 하한을 낮출 수 있는지 검증하는 것이었다.
- 재검증 결과 이 설정은 AWGN 하에서 **원리적으로 닫혀 있었고**(§4.2), 질문은 다음으로 교체되었다:
  > *dechirp 통계량이 최적이 아니게 되는 조건은 무엇이며, 그 조건에서 남는 여지는 정량적으로 얼마인가?*

## 2. 접근

- **Complex-valued BAM (Bidirectional Associative Memory) 설계**
  - 가중치 `W_uv`, `W_vu` 를 실제 복소수로 유지 (실수 concat 아님).
  - 활성함수는 **split-tanh** — IEEE 논문의 Lagrange 안정성 조건을 만족하도록 선택.
  - 동역학은 Euler 적분으로 forward-backward를 반복.
- **구조 실험**
  - Noise2Noise 자가지도 학습
  - 스킵 커넥션 / outer residual / tied-untied encoder 등 다수 변형
  - Complex 스펙트로그램 입력 · IQ 직접 입력 두 도메인 모두 시도

### 3.2 재검증 — 이 개선은 baseline의 구현 손실을 되찾은 것이었다

`verification/folding.py` 에서 **동일한 노이즈 실현**으로 세 detector를 비교했다
(6000 trials/SNR, 괄호는 95% Wilson 신뢰구간).

| SNR | README 부록 이전 버전 `power[:512]` | repo detector (OSF-fold) | **matched filter (= ML)** |
|---|---|---|---|
| -30 dB | 2.1% [1.8, 2.5] | 1.7% [1.4, 2.1] | **8.3% [7.7, 9.1]** |
| -25 dB | 13.4% [12.6, 14.3] | 13.0% [12.2, 13.9] | **52.6% [51.4, 53.9]** |
| -20 dB | 44.0% [42.8, 45.3] | 74.5% [73.4, 75.6] | **99.6% [99.4, 99.7]** |
| -15 dB | 65.5% [64.3, 66.7] | 98.9% [98.6, 99.2] | **100.0% [99.9, 100.0]** |

정확도 차이를 dB로 환산하기 위해 ML의 정확도-SNR 곡선을 0.5 dB 격자로 만들고 각 detector의
정확도를 그 곡선에 역투영했다 (folding.py [3b]). **repo detector의 실질 손실은 평균 4.2 dB** 다
(이전 README는 "약 5 dB"로 적었으나, 이 환산이 더 정확하다).

그 결과:

> **BAMv3의 -25 dB 27.8% 는, 같은 조건에서 아무것도 학습하지 않은 matched filter 의 52.6% [51.4, 53.9] 에 크게 못 미친다.**
> 즉 1차 결과의 "개선"은 최적 detector를 넘어선 것이 아니라, **baseline이 스스로 버리고 있던 손실의 일부를 신경망이 되찾아준 것**이다.
> 올바른 baseline을 쓰면 이 개선폭은 남지 않는다.

### 3.3 왜 dechirp+FFT가 손실인가 — folding 질문에 대한 답

이 지점에서 당연한 반론이 나온다.

> "OSF=4에서 alias 두 조각을 **복소합**으로 합치면 최적 검출기가 되는 것 아닌가?
>  그러면 최적 검출기는 512-FFT 한 번으로 끝나는 것 아닌가?"

`verification/folding.py` 가 이 질문에만 답한다. 결론부터: **복소합으로는 안 된다. 그러나
512-FFT 한 번으로 끝난다는 결론 자체는 맞다 — 순서가 다를 뿐이다.**

**(a) 조각의 정체.** dechirp된 심볼 `c_m[n] = X[m][n]·conj(upchirp[n])` 은 *같은 톤의 복제본
두 개*가 아니라 **겹치지 않는 두 시간 구간**이다.

```
n <  n0 : bin m      의 톤
n >= n0 : bin m-512  의 톤   (= bin m 톤 x (-j)^n, 주파수가 정확히 -BW 만큼 점프)
경계  n0 = L - OSF*m  <- cyclic shift 의 wrap 위치. 심볼마다 다르다.
```

따라서 두 bin이 담는 에너지 비율은 `(n0^2 + (L-n0)^2)/L^2` 이며 심볼에 따라 **100% ~ 50%** 로
변한다. 측정치가 이 식과 소수 4자리까지 일치한다 (folding.py [1]). m=0은 wrap이 없어 한 조각,
m=256은 정확히 반반이다. 즉 손실은 상수가 아니라 **심볼 인덱스의 함수**다.

**(b) 가능한 모든 결합기의 손실은 몬테카를로 없이 계산된다.** 선형 결합기 `g` 의 출력 SNR은
`|<c_m,g>|^2 / (||g||^2 σ^2)` 이므로, ML 대비 손실은 `|<c_m,g>|^2/(||g||^2 ||c_m||^2)` 이다.

| 결합기 | 평균 손실 | 최선 | 최악 |
|---|---|---|---|
| bin m 하나만 (pre-fix `power[:512]`) | -4.76 dB | 0.00 dB | -54.19 dB |
| 2-bin 등이득 복소합 (EGC) | **-3.01 dB** | -3.01 dB | -3.01 dB |
| 2-bin MRC — **가능한 최선의 2-bin 결합** | -1.76 dB | 0.00 dB | -3.01 dB |
| **4-block 복소합** | **-6.02 dB** | -6.02 dB | -6.02 dB |
| 전 bin MRC (= matched filter) | 0.00 dB | 0.00 dB | 0.00 dB |

**(c) 실측** (6000 trials/SNR, 동일 잡음 실현, 95% Wilson CI, 마지막 열은 direct MF bank와 판정이
일치한 비율):

| detector | -30 dB | -25 dB | -20 dB | -15 dB | 등가 손실 | MF 판정 일치 |
|---|---|---|---|---|---|---|
| pre-fix `power[:512]` | 2.1% [1.8,2.5] | 13.4% [12.6,14.3] | 44.0% [42.8,45.3] | 65.5% [64.3,66.7] | -5.56 dB | 34.4% |
| repo 4-block 전력합 (비결맞음) | 1.7% [1.4,2.1] | 13.0% [12.2,13.9] | 74.5% [73.4,75.6] | 98.9% [98.6,99.2] | -4.19 dB | 48.8% |
| 신호블록 2개 전력합 (비결맞음) | 3.0% [2.6,3.4] | 20.7% [19.7,21.7] | 82.9% [81.9,83.8] | 99.1% [98.8,99.3] | -3.46 dB | 55.4% |
| **4-block 복소합** | 0.9% [0.7,1.2] | **5.3% [4.8,5.9]** | 37.1% [35.9,38.3] | 97.4% [96.9,97.7] | **-6.09 dB** | 36.3% |
| 4-데시메이션 + 512-FFT | 0.9% [0.7,1.2] | **5.3% [4.8,5.9]** | 37.1% [35.9,38.3] | 97.4% [96.9,97.7] | -6.09 dB | 36.3% |
| 2-bin 등이득 복소합 | 2.9% [2.5,3.3] | 18.6% [17.6,19.6] | 82.5% [81.5,83.5] | 100.0% | -2.97 dB | 54.6% |
| 2-bin MRC (최적 2-bin) | 4.8% [4.3,5.4] | 24.6% [23.5,25.7] | 81.8% [80.8,82.7] | 100.0% | -2.62 dB | 59.9% |
| **대역제한+데시메이션, 512-FFT** | 7.8% [7.1,8.5] | **51.6% [50.4,52.9]** | 99.5% [99.2,99.6] | 100.0% | **-0.07 dB** | 90.3% |
| 대역제한+데시메이션, 512-MF | 8.1% [7.4,8.8] | 52.2% [51.0,53.5] | 99.6% [99.3,99.7] | 100.0% | +0.01 dB | 93.1% |
| **FFT-MF** | 8.3% [7.7,9.1] | **52.6% [51.4,53.9]** | 99.6% [99.4,99.7] | 100.0% | +0.06 dB | **100.0%** |
| direct MF bank (기준 ML) | 8.3% [7.7,9.1] | 52.6% [51.4,53.9] | 99.6% [99.4,99.7] | 100.0% | 0 dB | 100.0% |

읽는 법은 세 줄이다.

1. **복소 folding은 54%를 주지 않는다. 5.3% [4.8, 5.9] 를 준다.** 고치려던 repo detector의
   13.0% 보다도 **낮다.** 따라서 "최적 검출기는 4-블록을 복소로 합치면 된다"는 가설은 기각된다.

2. **원인은 위상 불일치가 아니다. 구현은 맞다.** 두 가지로 확인했다 — (i) 주파수영역 4-블록
   **복소**합과 시간영역 4-데시메이션 후 512-FFT가 상대오차 `4.8e-17` 로 **동일**하고
   (folding.py [0]), (ii) 두 검출기의 판정이 6000 trials에서 100% 일치한다. 크기합과는 상관계수
   0.76으로 명확히 다른 통계량이다. 즉 복소합을 제대로 한 것이 맞다.
   진짜 원인은 **잡음 aliasing** 이다. 4-블록 복소합은 정의상 *대역제한 없는* 4:1 데시메이션이고,
   1 MHz에 퍼져 있던 잡음을 250 kHz로 4배 접어 넣는다. 신호는 그대로, 잡음만 4배 → **정확히
   6.02 dB**. 해석적 예측 -6.02 dB, 실측 등가 손실 -6.09 dB로 일치한다.

3. **그리고 "512-FFT 한 번"이라는 직관 자체는 맞다 — 데시메이션 *전에* 대역제한을 하면 된다.**
   `|f| < BW/2` 로 자른 뒤 4:1로 내리고 512-point dechirp+FFT를 하면 51.6% [50.4, 52.9] 로,
   ML의 52.6% [51.4, 53.9] 와 **신뢰구간이 겹치고** 판정도 90.3% 일치하며 등가 손실은 -0.07 dB다.
   표준 LoRa 수신기가 `fs = BW` 에서 도는 것이 우연이 아닌 이유가 이것이다. 이 저장소의 실수는
   OSF>1에서 **대역제한 없이** BW-rate 알고리즘을 그대로 쓴 것이었다.

**bin을 더 모으면 되지 않나?** top-K bin MRC의 포착 에너지는 K=1에서 58.3%, K=2에서 66.7%,
K=8에서 89.7%, K=32에서 97.8%다 (folding.py [4]). ML에 닿으려면 사실상 전 bin을 **심볼별 복소
가중치**로 모아야 하고, 그것은 정의상 matched filter다. bin 2개로는 닫히지 않는다.

> **철회:** 이전 판 §3.2의 "신호 블록 2개 non-coherent / coherent 합" 두 행은 블록 0과 **1** 을
> 더한 값이었다. 신호가 실린 블록은 0과 **3** 이므로(에너지 비율 80.4% / 19.6% 대 0.01%),
> 그 행들은 순수 잡음 블록을 더한 셈이고 folding의 한계를 **과소평가**했다. 위 표가 이를 대체한다.
> 결론(격차가 folding 개수 문제가 아니라는 것)은 유지되지만, 근거는 완전히 교체되었다.

### 3.4 그 최적 detector는 엣지에서 돌아간다 (연산량 1.1배)

"MF가 최적이지만 512×2048 상관은 기기에서 못 돌린다"는 반론은 성립하지 않는다.
`X[m] = roll(X[0], -OSF·m)` 이 **정확히** 성립하므로 512개 프로토타입 상관은 전부 하나의
순환상관이다. 게다가 필요한 lag가 4의 배수뿐이므로 역변환은 512-point로 충분하다
(folding.py [0]에서 상대오차 `1.1e-16` 으로 확인).

> **정정:** 이전 판은 이를 "FFT 2회, 연산량 1.5배"로 적었다. 2048-point IFFT는 불필요하다.
> **2048-FFT 1회 + 512-IFFT 1회**이며, 실측 비용은 **1.1배**다.

| detector | 심볼당 비용 | 기존 대비 | -25 dB 정확도 |
|---|---|---|---|
| repo dechirp+2048FFT (FFT 1회) | 60.3 µs | 1.00× | 13.0% [12.2, 13.9] |
| 대역제한+데시메이션+512FFT | 64.4 µs | 1.07× | 51.6% [50.4, 52.9] |
| **FFT-MF (2048FFT 1 + 512IFFT 1)** | **66.3 µs** | **1.10×** | **52.6% [51.4, 53.9]** |
| FFT-MF (2048FFT 2회, 이전 판) | 86.5 µs | 1.43× | 52.6% |
| direct MF bank (512×2048) | 377.7 µs | 6.26× | 52.6% |

FFT-MF는 direct MF와 **판정이 100% 일치**한다(근사가 아니라 등가). 비용 수치는 NumPy 호출
오버헤드를 포함한 벽시계 시간이므로 절대값이 아니라 비율로 읽어야 한다. 실제 게이트웨이는
프론트엔드에서 이미 심볼률로 내려받으므로, 그 경우 복조는 **512-FFT 1회**로 끝나고 그것이 ML이다.

> **복조 성공률을 올리는 가장 큰 단일 요인은 신경망이 아니라 detector 교체였다.**
> -25 dB 에서 **13.0% → 52.6% (+39.6%p, 95% CI 로도 겹치지 않음)**, 학습 없이, 클라우드 없이.
> 같은 지점에서 BAMv3가 만든 개선은 +9%p 였고, 그것은 이 39.6%p 안에 포함되는 부분집합이었다.

이 사실은 백홀/C-RAN 논의 자체를 무효화한다. **IQ를 클라우드로 보낼 이유가 없다.**
초저 SNR에서 복조가 안 되던 원인의 대부분은 SNR이 아니라 게이트웨이 측 detector 손실이었다.

## 4. 종료 근거 — 두 번 바뀌었다

### 4.1 처음 세웠던 근거 (SOM 군집 실패) — **철회**

처음에는 "초저 SNR LoRa IQ는 심볼 구분 정보를 담고 있지 않다"는 결론을 SOM 실험에서 끌어냈다.

![STFT-SOM Label Map](local/SOM.png)

SOM 격자 위에서 같은 label이 연속 영역을 이루지 못하고 파편화된 것은 **사실**이다.
그러나 `verification/verify.py` 로 **노이즈가 전혀 없는 clean 심볼 512개의 기하 구조**를 직접 재보았다.

```
|cos| between DIFFERENT symbols : mean=0.00350  max=0.02169
normalized L2 distance          : mean=1.41426  min=1.39892  max=1.42947
  -> ratio max/min = 1.0218      (1.0 == 완전 등거리)
mean dist to NEIGHBOUR (m, m+1)  = 1.41283
mean dist to OPPOSITE (m, m+256) = 1.41421
```

**LoRa 심볼 집합은 설계상 서로 거의 직교하며, 따라서 IQ 공간에서 거의 완전한 등거리 배치다.**
이는 Chiani & Elzanaty [2] 가 닫힌 형태로 보인 성질의 수치적 확인이다 (§7.1).
심볼 인덱스가 가깝든 멀든 거리는 동일하다 (1.41283 vs 1.41421).

즉 SOM은 **SNR = +∞ 에서도 군집을 만들 수 없다.** 군집 실패는 노이즈나 정보량과 무관하며,
직교 codebook이면 당연히 나오는 결과다. 관측은 맞았지만 **거기서 끌어낸 결론이 틀렸다.**
이 근거는 종료 사유로 쓸 수 없다.

### 4.2 실제 종료 근거 — AWGN 구간에서는 정리(theorem)로 닫힌다

LoRa 심볼 512개는 **등에너지 · 근사 직교 신호 집합**이다 (§4.1의 |cos| ≈ 0.0035 가 그 측정치다).
AWGN 하에서 이런 집합의 최적 검출기는 512개 프로토타입 전체에 대한 noncoherent matched filter이고,
그 상관 벡터 `{|p_m^H y|}` 가 **충분통계량(sufficient statistic)** 이다.
이 최적성은 Vangelista [1] 가 FSCM 정식화에서 유도한 결과이며, 본 연구의 독립적 주장이 아니다 (§7.1).
(§3.4 에서 보았듯 이 통계량은 2048-FFT 1회 + 512-IFFT 1회로 정확히 계산된다. 이 저장소가 쓰던 dechirp+FFT 는
그 MF의 손실 있는 변형이었을 뿐, 최적성과 저연산은 양립한다.)

따라서 심볼 단위 front-end `g(y)` 를 앞에 붙이는 모든 구조는 data processing inequality [12] 에 의해
**정보를 늘릴 수 없고, 잘해야 보존한다.**

> **AWGN · 심볼 단위 · denoising front-end 라는 조합은 성능 향상 여지가 0 임이 증명되어 있다.**
> BAM이든 CNN이든 diffusion이든 구조를 바꿔도 결과는 같다.
> 이 연구 라인의 종료는 실험적 실패가 아니라 **문제 설정이 닫혀 있었다는 사실**에 근거한다.

§3.2 의 측정은 이 정리의 따름정리(corollary)를 그대로 보여준다 — 개선처럼 보인 것의 정체는
baseline이 최적이 아니었다는 것뿐이었다.

## 5. 그렇다면 열려 있는 조건은 무엇인가 — CFO 재정의

"AWGN에서 닫혀 있다"는 것은 **비최적성이 존재하는 조건에서만 학습 기반 접근이 의미를 가진다**는 뜻이다.
CFO(carrier frequency offset)는 그 조건에 해당한다. CFO가 있으면 zero-CFO 프로토타입에 맞춰진
dechirp 통계량은 더 이상 충분통계량이 아니다. 초저 SNR + 하드웨어 임페어먼트 하에서
신경망 복조를 다루는 기존 연구 라인(NELoRa [10] 등)이 겨냥하는 지점도 여기다 (§7.3).

**여지가 실제로 있는지, 있다면 얼마이며, 고전적 방법이 이미 그것을 다 먹는지**를 측정했다.
baseline 은 한 단계씩 올린다 — blind MF → 심볼단위 joint 탐색 → 패킷 상수-CFO 추정 →
**drift-aware 2D 추정** → genie(상한). 약한 baseline 하나만 놓고 "고전 방법이 실패한다"고
말하면 허수아비가 되기 때문이다. 실제로 이 사다리를 올리는 과정에서 이전 판의 결론 두 개가
뒤집혔다 (§5.3, §5.5).

측정 스크립트: `verification/cfo_ci.py` (§5.1–§5.4), `verification/grid_refine.py` (§5.3),
`verification/drift_baseline.py` (§5.5–§5.6). 이전 판의 `cfo_headroom.py` · `pkt_test.py` ·
`break_test.py` 는 같은 실험의 저-trial · 무-CI 버전이며 참고용으로 남겨 두었다.

### 5.1 CFO는 실제로 여지를 만든다

residual CFO ε (bin 단위, 1 bin = 488.28 Hz) 를 고정했을 때 matched filter 정확도
(`verification/cfo_ci.py` [A], 20000 trials/cell, 95% Wilson CI):

| SNR | ε=0 | ε=0.10 | ε=0.25 | ε=0.50 |
|---|---|---|---|---|
| -30 dB | 8.4% [8.0, 8.7] | 7.8% [7.4, 8.2] | 5.7% [5.3, 6.0] | 2.2% [2.0, 2.4] |
| -25 dB | 53.1% [52.4, 53.8] | 50.3% [49.6, 51.0] | 39.0% [38.4, 39.7] | 11.8% [11.3, 12.2] |
| -20 dB | 99.6% [99.5, 99.7] | 99.4% [99.3, 99.5] | 97.9% [97.7, 98.1] | 44.7% [44.0, 45.4] |
| -15 dB | 100.0% [100.0, 100.0] | 100.0% [100.0, 100.0] | 100.0% [100.0, 100.0] | 49.8% [49.1, 50.5] |

ε=0.5 bin 에서 고 SNR에서도 49.8% [49.1, 50.5] 로 주저앉는 것은 peak이 두 bin 정확히 사이에
놓이는 구조적 모호성이다. **CFO는 SNR로 극복되지 않는 손실을 만든다.**

### 5.2 그러나 여지의 지렛대는 "심볼 단위 denoising"이 아니다

ε ~ U(-0.5, 0.5) bin, 패킷 내 상수 (물리적으로 맞는 모델). 300 packets × 128 symbols/cell.
**CI는 심볼이 아니라 패킷을 재표집한 부트스트랩이다** — 같은 패킷 안의 심볼은 하나의 CFO 추정을
공유하므로 독립이 아니고, 심볼 단위 이항 CI는 유효 표본수를 과대평가한다.

| SNR | blind MF | 심볼단위 joint | 패킷 ns=8 | ns=32 | ns=128 | genie (CFO 기지) | headroom |
|---|---|---|---|---|---|---|---|
| -30 dB | 5.6% [5.3, 5.9] | 5.8% [5.5, 6.1] | 5.3% [5.0, 5.5] | 5.5% [5.2, 5.8] | 5.8% [5.3, 6.2] | 8.1% [7.8, 8.4] | 2.5%p [2.2, 2.9] |
| -25 dB | 36.1% [34.7, 37.5] | 41.1% [40.2, 41.9] | 45.0% [44.1, 45.9] | 48.9% [47.9, 49.8] | **50.5% [49.4, 51.4]** | 52.1% [51.6, 52.6] | 16.0%p [14.5, 17.5] |
| -20 dB | 89.2% [87.5, 90.8] | 90.2% [88.7, 91.5] | 94.9% [93.7, 96.0] | 97.3% [96.4, 98.2] | **99.5% [99.5, 99.6]** | 99.5% [99.4, 99.6] | 10.3%p [8.7, 12.0] |
| -15 dB | 96.2% [95.1, 97.3] | 94.6% [93.4, 95.8] | 97.9% [97.2, 98.5] | 99.6% [99.2, 99.9] | **100.0%** | 100.0% | 3.8%p [2.7, 4.9] |

-25 dB 기준 headroom 은 **16.0%p [14.5, 17.5]** 로 작지 않다. 그런데 **심볼 하나만 보는 joint
탐색은 그중 5.0%p 밖에 못 가져온다.** 초저 SNR에서 심볼 하나는 자기 CFO를 추정할 SNR 자체가
없다. 반면 심볼을 가로질러 pooling 하면 대부분이 회수된다 (ns=128 → 14.4%p 회수).

> **이것이 06번 실험(심볼 단위 Complex IQ BAM)이 구조적으로 도달할 수 없었던 이유다.**
> CFO 구간의 여지는 심볼 내부가 아니라 **심볼들 사이의 공유 구조**에 있다.
> 어떤 per-symbol autoencoder/BAM도 이 여지에 접근할 수 없다.

> **정정:** 이전 판은 headroom 을 19.8%p 로, 그리고 "ns=128 이면 genie와 동일"로 적었다
> (1280 trials, CI 없음). 300 패킷으로 다시 재면 -20 dB 이상에서는 실제로 genie와 같지만
> **-25 dB 에서는 1.6%p 가 남고, -30 dB 에서는 pooling 이 사실상 아무것도 회수하지 못한다**
> (5.8% vs genie 8.1%). §5.3 이 그 지점을 다룬다.

### 5.3 정적 CFO라도 깊은 SNR에서는 고전 추정기가 상한에 못 닿는다 — **이전 판의 반대 결론**

이전 판은 여기서 "-28 dB 까지 단순 grid search 기반 패킷 CFO 추정이 genie 상한과 사실상 같다"고
적고, 그로부터 "정적 CFO 에서 신경망 우위 주장 불가"를 끌어냈다. 근거는 1024 심볼 · CFO 추첨 2회
기준의 표였고 신뢰구간이 없었다. 격차로 제시된 0.3%p / -0.4%p 는 표준오차 안에 있었다.

### 5.5 그러나 drift 를 모델에 넣으면 고전 방법이 대부분 회수한다 — **이전 판의 주장 축소**

§5.4 만으로는 약하다. 리뷰어는 반드시 묻는다: *"상수-CFO 추정기가 허수아비 아닌가?
drift 를 모델에 넣은 고전 추정기를 쓰면 되는 것 아닌가?"* SFO/드리프트는 LoRa 문헌에서 이미
알려진 문제이고, preamble 기반 추정·보상이 표준적 대응이다 [5, 6, 7].

| **2.00** | 19.4% [19.0, 19.8] | 19.2% [18.8, 19.7] | **51.4% [49.9, 52.7]** | 53.3% [52.6, 53.9] | 1.83%p [0.70, 3.21] | **+32.21%p [30.78, 33.48]** |

**선형 drift 에서는 2D 추정기가 대부분을 회수한다.** drift = 1 bin 에서 1D 대비 +24.16%p
[22.23, 26.10] 를 되찾아 50.0% 에 이르고, genie(52.4%) 와의 격차는 2.40%p [1.14, 3.88] 로
줄어든다. drift = 0 에서 2D 는 1D 대비 손해가 없다 (−0.03%p, p=0.73) — 차원을 늘린 대가를
치르지 않는다는 뜻이다.

> **정정:** 이전 판은 "약 28%p 의 여지가 **어떤 상수-CFO 고전 추정기로도** 접근 불가능한 상태로
> 남아 있다"고 적었다. 문장 자체는 참이지만(상수-CFO 추정기에 한정하므로) **오도한다.**
> 상수-CFO 는 고전 방법의 상한이 아니다. 자연스러운 고전적 확장인 2-파라미터 탐색을 쓰면
> 선형 drift 구간에서 그 여지의 대부분이 회수된다. **선형 drift 는 열린 조건이 아니다.**

### 5.6 실제로 열려 있는 조건 — drift 가 저차 모델로 안 잡힐 때

§5.5 가 닫은 것은 **선형** drift 다. 선형은 2개의 파라미터로 기술되고, 고전 추정기가 그 2개를
찾으면 끝난다. 그렇다면 남는 질문은 하나다: **drift 가 저차 파라메트릭 모델로 기술되지 않으면
어떻게 되는가?** 물리적으로 이쪽이 오히려 일반적이다 — 온도 변화, 전원 변동, 진동에 따른
발진기 위상 잡음은 램프가 아니다.

같은 조건에서 drift 를 **심볼 단위 random walk** 로 바꿔 다시 쟀다 (패킷 전체 표준편차를
변화폭으로 표기, 나머지 설정은 §5.5 와 동일):

| 패킷 내 CFO 표준편차 (bin) | blind MF | 상수-CFO (1D) | **drift-aware (2D)** | genie | **genie − 2D** | 2D − 1D |
|---|---|---|---|---|---|---|
| 0.00 | 36.8% [34.9, 38.6] | 50.2% [48.4, 51.8] | 50.2% [48.4, 51.8] | 53.0% [52.4, 53.6] | 2.79%p [1.33, 4.49] | 0.00%p (판정 동일) |
| 0.50 | 33.6% [32.1, 35.0] | 41.1% [39.1, 42.9] | 43.9% [42.1, 45.6] | 52.3% [51.7, 52.9] | **8.35%p [6.71, 10.08]** | +2.84%p [1.10, 4.71] |
| **1.00** | 26.7% [25.5, 27.9] | 29.2% [27.7, 30.7] | 30.5% [28.7, 32.3] | 52.5% [51.9, 53.1] | **21.98%p [20.18, 23.88]** | +1.30%p [-0.57, 3.17] (p=0.17) |
| **2.00** | 17.2% [16.1, 18.2] | 16.7% [15.6, 17.9] | 17.6% [16.4, 18.8] | 52.4% [51.8, 53.0] | **34.84%p [33.50, 36.16]** | +0.82%p [-0.31, 1.97] (p=0.15) |

같은 변화폭에서 §5.5 의 선형 drift 와 나란히 놓으면 차이가 분명하다.

| 패킷 내 변화폭 (bin) | 선형 drift 의 genie − 2D | random walk 의 genie − 2D |
|---|---|---|
| 0.50 | 3.46%p [1.89, 5.23] | **8.35%p [6.71, 10.08]** |
| 1.00 | 2.40%p [1.14, 3.88] | **21.98%p [20.18, 23.88]** |
| 2.00 | 1.83%p [0.70, 3.21] | **34.84%p [33.50, 36.16]** |

선형 drift 는 변화폭이 커져도 격차가 **줄어든다** — 모델이 맞으므로 변화가 클수록 오히려 추정이
쉬워진다. random walk 는 정반대로 격차가 **단조 증가**한다. 그리고 변화폭 ≥ 1 bin 에서는
**기울기 차원을 추가해도 얻는 것이 없다** (2D − 1D 가 p=0.17, p=0.15 로 유의하지 않다).
상수-CFO 추정기도 blind 대비 아무것도 못 한다 (변화폭 2 bin 에서 -0.41%p, p=0.26).
세 baseline 이 모두 17% 부근에 몰려 있는 동안 genie 는 52.4% 를 유지한다.

> **이것이 이 연구에서 방어 가능한 유일한 "열린 조건"이다.**
> **초저 SNR + 정수-bin 횡단이 저차 모델로 예측되지 않는 시변 CFO 하의 sequence-level 복조.**
> 변화폭 1 bin 에서 **14.7%p [12.1, 17.4]**, 2 bin 에서 **32.4%p [30.7, 34.2]** 가
> 계산 가능한 상한과 함께 미회수로 남는다. 이 수치는 genie − 2D 가 아니라
> **genie − 모델 인지 추적기**이며(§5.7), **프리앰블 8 chirp 로 실제 동기를 잡은 뒤**의
> 값이다(§5.8). 완전 동기를 가정하면 1 bin 에서 22.1%p 로 과대평가된다. 고전 baseline 을 세 단계(상수 → drift-aware →
> 모델 인지 HMM 추적기) 올려도 닫히지 않으므로 비교 대상이 분명하고, 상한이 느슨해서
> 생긴 격차가 아니라는 것도 §5.7 에서 따로 확인했다.
>
> 반대로 **선형 drift 를 열린 조건으로 주장해서는 안 된다** (§5.5). 이 구분이 이번 재검증에서
> 가장 크게 바뀐 부분이다.

**유보 사항.** random walk 는 발진기 위상잡음의 편의적 대리모형이지 측정된 SFO 모형이 아니다.
실제 하드웨어의 drift 가 선형에 가까운지 random walk 에 가까운지는 실측으로 확인해야 하고,
논문에서는 이 모형 선택을 명시한 뒤 crystal ppm 단위로 환산해 제시해야 한다 (§8).

### 5.7 그 상한은 타당한가 — genie 감사

§5.6 의 격차는 genie − 2D 다. 그런데 genie 는 심볼 단위 CFO 궤적을 **전부** 안다. -25 dB 에서
심볼 하나는 자기 CFO 를 추정할 SNR 자체가 없고 (§5.2 — 심볼단위 탐색은 headroom 의 5.0%p 만
회수), 그렇다면 저 22 / 35%p 는 "미회수 여지"가 아니라 **"상한이 느슨한 것"** 일 수 있다.
둘은 논문에서 정반대의 주장이다. `verification/genie_audit.py` 가 이것을 가른다.
(아래는 §5.6 과 독립적인 실행이다 — 120 패킷 × 128 심볼, SNR -25 dB. 같은 표 안의 수치끼리만
비교해야 한다.)

**대조군이 먼저다.** 추적기가 맞게 구현됐다는 것을 독립으로 보이지 못하면 나머지 수치는 못 쓴다.

| 대조군 | 기준 | 결과 | 판정 |
|---|---|---|---|
| C1 정적 CFO (amp=0) | 추적기 == 상수-CFO 1D 추정기 | 추적기 − 1D fine = **+0.14%p** [−0.02, 0.31] p=0.10 | PASS |
| C2 선형 drift 1 bin | 추적기 ≥ drift-aware 2D | **−1.15%p** [−2.53, −0.15] (격자 이산화 허용폭 1.5%p 내) | PASS |
| C2 선형 drift 2 bin | 추적기 ≥ drift-aware 2D | **+0.32%p** [−1.02, 1.78] p=0.68 | PASS |

허용폭 1.5%p 의 근거는 `verification/grid_conv.py` 다 — 상태격자를 0.06 → 0.0075 로 좁히면
CFO 추정 RMSE 가 0.067 → 0.029 bin 으로 단조 수렴하고 추적기 − 2D 는 0 근방에 머문다.
즉 남는 잔차는 구현이 아니라 격자 몫이다.

**(A) 블록-genie — 시간 해상도는 병목이 아니다.** genie 에게 참 궤적을 B 심볼 블록평균으로만 준다.
B=1 이 현재 genie, B=128 이 패킷-상수 genie 다.

| 조건 | B=1 | B=8 | B=16 | B=32 | B=64 | B=128 | blind |
|---|---|---|---|---|---|---|---|
| walk 0.50 | 52.1% | 51.5% | 51.1% | 50.0% | 47.8% | 43.9% | 34.0% |
| walk 1.00 | 52.5% | 50.3% | 48.0% | 44.0% | 39.1% | 32.3% | 27.2% |
| walk 2.00 | 52.7% | 44.7% | 40.0% | 33.0% | 25.9% | 19.0% | 18.4% |

walk 1 bin 에서 **8 심볼 블록평균만 알아도 50.3%** 가 나온다 (B=1 대비 −2.14%p). 8~16 심볼
블록은 심볼 하나보다 SNR 이 9~12 dB 높아 **원리적으로 추정 가능한 영역**이다. 따라서
"심볼당 SNR 이 없으므로 genie 는 도달 불가능한 상한"이라는 가설은 **기각된다.**

**(B) 모델 인지 추적기 — side info 없이 모델만 아는 수신기.** CFO 격자(±1.5 bin, 0.03) 위 HMM,
미지 심볼을 주변화한 우도, 참 증분분산을 아는 가우시안 전이, 전방-후방 스무딩 후 사후분포로
ε 을 주변화해 심볼을 판정한다.

| 조건 | blind | 1D | 2D | **추적기** | genie | **genie − 추적기** | 추적기 − 2D |
|---|---|---|---|---|---|---|---|
| walk 0.00 | 35.3% | 51.0% | 50.9% | **52.2%** | 52.3% | **0.08%p** [−0.09, 0.23] p=0.36 | +1.32%p |
| walk 0.50 | 34.0% | 41.7% | 43.6% | 40.6% | 52.1% | 11.53%p [8.27, 15.12] | −3.00%p (p=0.083) |
| **walk 1.00** | 27.2% | 28.7% | 28.9% | 30.4% | 52.5% | **22.12%p [19.19, 25.10]** | +1.46%p (p=0.44) |
| **walk 2.00** | 18.4% | 18.1% | 18.6% | 20.6% | 52.7% | **32.10%p [30.45, 33.72]** | +2.03%p (p=0.047) |
| linear 1.00 | 30.3% | 27.8% | 52.5% | **51.3%** | 53.3% | 1.96%p [0.68, 3.61] | −1.15%p |
| linear 2.00 | 19.3% | 18.8% | 51.8% | **52.1%** | 53.0% | **0.90%p** [0.32, 1.86] | +0.32%p |

두 가지가 동시에 나온다.

1. **추적기는 조건만 맞으면 상한에 정확히 닿는다.** 정적 CFO 에서 genie 와의 차이가
   0.08%p (p=0.36) 로 통계적으로 구별되지 않고, 선형 drift 2 bin 에서도 0.90%p 다.
   **그러므로 walk 에서 못 닿는 것은 추적기가 약해서가 아니다.**
2. **walk 에서는 추적기가 2D 대비 아무것도 회수하지 못한다** (+1.32 / −3.00 / +1.46 / +2.03 %p,
   어느 셀도 뚜렷한 양수가 아니다). §5.6 의 격차가 상한을 실제 수신기로 바꿔도 남는다.

**(C) 왜 남는가 — 정수부(alias) 교락.** 미지 심볼을 균등 주변화한 우도는 ε 에 대해
**주기 1 bin 으로 정확히 주기적**이다. CFO 를 정확히 1 bin 옮기는 것과 데이터 심볼을 1 칸
순환이동시키는 것이 같기 때문이다. 즉 **ε 의 정수부는 데이터 심볼과 교락되어 심볼 단위로는
원리적으로 관측 불가능**하고, genie 는 그것을 안다. 소수부를 완벽히 알아도 정수부를 모르면
(`verification/alias_split.py`):

| 조건 | 정수부 ≠ 0 인 심볼 | genie 소수부만 | genie 전부 | **정수부 교락 손실** |
|---|---|---|---|---|
| walk 0.50 | 17.2% | 43.3% | 52.2% | 8.91%p [7.34, 10.55] |
| walk 1.00 | 34.0% | 34.3% | 51.9% | 17.61%p [15.88, 19.42] |
| walk 2.00 | 54.9% | 23.5% | 52.2% | 28.71%p [27.08, 30.36] |
| linear 1.00 | 26.1% | 38.9% | 52.4% | 13.52%p [12.07, 14.93] |
| linear 2.00 | 50.4% | 25.8% | 52.1% | 26.33%p [25.81, 26.84] |

손실이 정확히 **P(n ≠ 0) × p_genie** 를 따른다 (0.549 × 52.2 = 28.7 ✓, 0.340 × 51.9 = 17.6 ✓,
0.172 × 52.2 = 8.98 ✓, 0.504 × 52.1 = 26.3 ✓). 정수 bin 밖에 있는 심볼은 정수부를 모르면
그대로 틀린다는 뜻이다.

**결정적 대비가 여기 있다.** linear 2 bin 도 심볼의 50.4% 가 정수 경계를 넘고 교락 손실이
26.33%p 인데, 추적기는 genie 에 0.90%p 까지 닿는다. 즉 **궤적 연속성만으로 alias 정보를 전부
회수할 수 있다 — 단 궤적이 예측 가능할 때만.** random walk 는 증분이 예측 불가능하므로
연속성이 그 일을 하지 못한다.

> **감사 결과: genie 는 느슨한 상한이 아니다.**
> 블록-genie 는 시간 해상도가 병목이 아님을 보이고 (B=8 에서 50.3%), 모델 인지 추적기는
> 정적 CFO 와 선형 drift 에서 상한에 실제로 닿는다 (0.08 / 0.90%p). 그럼에도 random walk 에서는
> **22.1%p / 32.1%p** 가 남는다. 열린 조건은 "저차 모델로 기술되지 않는 시변 CFO" 보다
> 더 좁게 특정할 수 있다 — **정수-bin 횡단이 저차 모델로 예측되지 않는 시변 CFO.**

**유보 사항 세 가지.**

1. **추적기는 하나의 추적기다.** "어떤 수신기도 못 한다"를 증명하지 않는다. 다만 walk 0.0 과
   선형 drift 에서 상한에 닿는 것이 확인됐으므로 "추적기가 약해서"라는 설명은 배제된다.
2. **우도 근사를 잘못 쓰면 격차가 과대평가된다.** 비간섭 우도를 소인수 근사
   (|corr|²/σ², 즉 log I₀(z) ≈ z²/4) 로 쓰면 walk 0.5 에서 추적기가 40.6% → 32.8% 로 떨어져
   격차를 **7.8%p 부풀린다.** 여기서는 z 의 전형값이 ~13.9 라 그 근사가 성립하지 않는다.
   `genie_audit.py` 는 두 형태를 모두 낸다.
3. **walk 2 bin 에서는 격자 폭이 결론을 바꾸지 않는다.** 참 ε 의 7.46% 가 ±1.5 밖인데도
   격자를 ±3.0 으로 넓히면 추적기가 20.6% → 17.6% 로 **더 나빠진다.** 보고한 32.10%p 는
   추적기에 유리한 쪽을 택한 값이라 보수적이다. 반면 walk 0.5 셀만은 패킷간 분산이 커
   CI 가 [36.9, 44.0] 로 넓고 재현성이 약하다.


### 5.8 프리앰블을 넣으면 — 동기가 어디까지 사주는가

§5.7 은 패킷 시작 CFO 를 base ~ U(−0.5, 0.5) 로 뒀다. 이는 **프리앰블이 정수 CFO 를
완벽히 해소했다**는 모델이다. 리뷰어가 물을 지점이 정확히 여기다: −25 dB 에서 프리앰블이
정말 그걸 할 수 있는가? σ_pre 를 가정하지 않고 **실제 추정기를 만들어 쟀다**
(`verification/preamble_residual.py`).

프리앰블은 LoRa 표준대로 up-chirp 8 개. 심볼이 0 으로 **기지**이므로 §5.7 의 1 bin alias 가
여기엔 없다 — 심볼을 주변화하지 않기 때문이다. 그래서 프리앰블은 원리적으로 정수부를 잡을 수
있고, 남는 문제는 SNR 뿐이다. 심볼당 상관후 SNR 8.11 dB, 8 개 풀링 17.14 dB.

| 조건 | 잔차 std | \|r\| 중앙값 | **P(\|r\|>0.5) = 정수부 오류** |
|---|---|---|---|
| walk 0.00 | 0.058 bin | 0.038 | **0.00%** |
| linear 2.00 | 0.059 bin | 0.067 | **0.00%** |
| walk 1.00 | 0.168 bin | 0.107 | 0.56% |
| walk 2.00 | 0.522 bin | 0.222 | **14.44%** |

정적 CFO 와 선형 drift 에서는 정수부 오류가 **0%** 다. §5.7 의 가정은 성립하고, 오히려
**보수적**이었다 — 실제 프리앰블은 잔차를 0.058 bin 으로 좁히는데 §5.7 은 수신기가 ±0.5 를
탐색하게 뒀다.

이제 페이로드를 프리앰블 추정치로 미리 보상하고 §5.7 의 arm 을 다시 돌린다. 모든 arm 에
같은 정보를 준다 — 궤적의 시작점이 0 근처라는 제약이다 (2D 는 offset − slope/2 에 건다).
genie 는 참 궤적을 알므로 영향받지 않는다.

| 조건 | blind | 1D | 2D | 추적기 | genie | **genie − 추적기** | §5.7 값 | 변화 |
|---|---|---|---|---|---|---|---|---|
| walk 0.00 | 52.1% | 52.6% | 52.3% | 53.0% | 53.1% | 0.11%p [−0.08, 0.31] | 0.08 | +0.03 |
| **walk 1.00** | 24.3% | 25.4% | 23.9% | **38.1%** | 52.7% | **14.66%p [12.14, 17.35]** | 22.12 | **−7.46** |
| **walk 2.00** | 14.1% | 13.9% | 13.2% | 20.7% | 53.1% | **32.36%p [30.67, 34.15]** | 32.10 | +0.26 |
| linear 2.00 | 8.7% | 11.1% | 51.6% | **52.0%** | 52.6% | 0.54%p [−0.14, 1.67] | 0.90 | −0.36 |

대조군 둘(walk 0.00, linear 2.00)은 그대로 통과한다. 그리고 **교차점이 드러난다.**

> **프리앰블 동기는 중간 정도의 drift 까지만 값을 한다.**
> walk 1 bin 에서는 격차의 3 분의 1 을 회수한다 (22.12 → 14.66%p, 추적기 30.4% → 38.1%).
> walk 2 bin 에서는 아무것도 회수하지 못한다 (32.10 → 32.36%p). 프리앰블은 **시작점만**
> 고정하는데, 변화폭이 2 bin 이면 패킷 중반에 그 정보가 이미 무의미해지고 프리앰블 자체도
> 정수부를 14.44% 틀린다.

이 교차점이 **동기 단계와 복조 단계의 인계 지점**을 정량화한다. 프리앰블 탐지·동기를 개선하는
연구 라인(§7.3 의 [10] 계열, 그리고 초저 SNR 프리앰블 탐지 연구)이 책임지는 구간이 어디까지이고,
어디서부터 페이로드 쪽 궤적 불확실성이 남는 문제가 되는지가 한 줄로 갈린다.

**유보 사항.** 심볼 타이밍은 정확히 안다고 본다 (저장소 전체가 그렇다). 실제 LoRa 는 down-chirp
2.25 개로 CFO 와 STO 를 분리하는데 여기서는 STO 가 0 이므로 그 단계를 생략했다. 또한 이 모델은
심볼 간 위상 연속성을 두지 않으므로(각 심볼의 CFO 위상이 0 에서 다시 시작한다) 프리앰블 결합은
비간섭만 쓴다. 간섭 결합이 가능한 모델이라면 프리앰블 잔차가 더 줄고, 그만큼 walk 1 bin 의
격차도 더 줄어들 것이다 — 즉 위 14.66%p 는 **상한 쪽 추정**이다.


## 6. 결론

연구 목표는 **초저 SNR에서 LoRa 복조 성공률을 올리는 것**이었고, 제약은 **게이트웨이/기기에서 돌아가야 한다**는 것이었다(IQ를 클라우드로 올리는 백홀 비용이 이득보다 크다). 그 목표 기준으로 정리하면:

**달성한 것 — -25 dB 복조 성공률 13.0% [12.2, 13.9] → 52.6% [51.4, 53.9] (+39.6%p), 엣지에서 동작**

경로는 예상과 달랐다. 개선을 만든 것은 신경망이 아니라, 최적 검출기가 **2048-FFT 1회 + 512-IFFT 1회로 정확히 계산된다**는 사실이었다 (§3.4). 기존 대비 연산량 1.1배, 학습 없음, 클라우드 없음. 백홀 문제는 애초에 풀 필요가 없었다 — 복조가 안 되던 원인의 대부분이 SNR이 아니라 게이트웨이 측 detector 손실이었기 때문이다.

**그 과정에서 스스로 폐기한 것 (세 번)**

1. **1차 결과(BAMv3 +9%p)를 폐기했다.** 그 9%p는 detector 교체가 주는 39.6%p의 부분집합이었다. -25 dB 에서 BAMv3 27.8% vs 학습 없는 FFT-MF 52.6% [51.4, 53.9]. 올바른 baseline 앞에서 남지 않는다. (§3.2)
2. **종료 근거로 쓰던 SOM 분석을 철회했다.** LoRa 심볼은 설계상 등거리라(거리비 1.0218) SOM은 **노이즈가 없어도** 군집을 만들 수 없다. 관측은 옳았고 해석이 틀렸다. (§4.1)
3. **그 재검증의 folding 분석과 CFO 결론도 다시 폐기했다.** folding 비교표는 신호가 없는 FFT 블록을 더한 값이었고("FFT 2회 / 1.5배"도 여기서 나온 오류다), §5.3 의 "고전 방법이 이미 상한에 닿는다"와 §5.5 의 "28%p 가 고전 방법으로 접근 불가능"은 둘 다 표준오차 안이거나 baseline 이 약해서 나온 결론이었다. (§3.3, §5.3, §5.5)

**종료 근거 — 문제 설정이 닫혀 있었다**

AWGN에서 프로토타입 상관이 충분통계량이므로(Vangelista [1]), 심볼 단위 front-end는 data processing inequality [12] 에 의해 정보를 늘릴 수 없다. BAM이든 CNN이든 diffusion이든 같다. 이 라인의 종료는 실험 실패가 아니라 **정리(theorem)** 에 근거한다. (§4.2)

**남겨둔 것 — 여지의 지도**

학습이 의미를 갖는 곳은 ML이 최적이 아니게 되는 조건뿐이다. CFO가 그렇다. 신뢰구간을 붙여 다시 재면 지도는 이렇게 그려진다.

- CFO는 -25 dB에서 **16.0%p [14.5, 17.5]** 의 여지를 만든다 (blind 36.1% vs genie 52.1%). (§5.1–§5.2)
- 그 여지는 **심볼 단위로 도달 불가능하다** — 심볼단위 탐색은 5.0%p만 회수, 패킷 pooling(ns=128)은 14.4%p 회수. 06번 실험이 구조적으로 닿을 수 없었던 이유다. (§5.2)
- **정적 CFO 라도 -26 dB 이하에서는 고전 패킷 추정기가 상한에 못 닿는다** (격차 1.0 ~ 2.9%p, 모두 유의). grid 를 4배 촘촘히 해도 남으므로 양자화가 아니라 추정 실패다. 다만 절대 정확도가 낮아 실용적 의미는 제한적이다. (§5.3)
- **시변 CFO 에서 상수-CFO 추정기는 blind 보다 유의하게 나빠진다** (drift 1 bin 에서 27.4% vs 30.1%, 차이 −2.66%p [−3.61, −1.70]). 모델 불일치가 추정을 능동적으로 망가뜨린다. (§5.4)
- **그러나 선형 drift 는 열린 조건이 아니다.** offset × 기울기 2D 탐색이라는 자연스러운 고전적 확장이 drift 2 bin 에서도 51.4% 를 내고 genie 와 1.83%p [0.70, 3.21] 차이까지 좁힌다. (§5.5)
- **열린 조건은 정수-bin 횡단이 저차 모델로 예측되지 않는 시변 CFO 다.** drift 를 심볼 단위 random walk 로 주면 2D 탐색도 무력해지고(2D − 1D 가 p=0.17 / p=0.15 로 유의하지 않음), 변화폭 1 bin 에서 **14.7%p [12.1, 17.4]**, 2 bin 에서 **32.4%p [30.7, 34.2]** 가 상한과 함께 미회수로 남는다 — 프리앰블로 실제 동기를 잡은 뒤의 값이다. (§5.6, §5.7, §5.8)
- **그 상한이 느슨한 것이 아님을 따로 확인했다.** ⑴ genie 에게 궤적을 8 심볼 블록평균으로만 줘도 50.3% 가 나오므로 시간 해상도가 병목이 아니고, ⑵ side info 없는 모델 인지 HMM 추적기가 정적 CFO 에서 genie 와 0.08%p (p=0.36), 선형 drift 2 bin 에서 0.90%p 까지 닿는다. 그럼에도 random walk 에서만 격차가 남는다. 원인은 **ε 의 정수부가 데이터 심볼과 정확히 교락**되는 것이고(우도가 ε 에 대해 주기 1 bin), 그 손실이 **P(n≠0) × p_genie** 를 정확히 따른다. (§5.7)

→ 후속 연구의 방어 가능한 설정: **초저 SNR + 비파라메트릭 시변 CFO 하의 sequence-level 복조.** 상한이 계산 가능하고, 고전 baseline 을 두 단계 올려도 닫히지 않으므로 성과를 수치로 증명할 수 있다.

**이 저장소의 산출물**

"초저 SNR LoRa에 신경망을 붙여봤다"가 아니라,

> **복조 성공률을 실제로 올린 요인을 찾아내고(+39.6%p, 엣지 동작), 자신의 1차 결과와 1차 결론을, 그리고 그 재검증까지 세 번에 걸쳐 스스로 반증했으며, 어느 조건이 정리로 닫혀 있고 어느 조건이 계산 가능한 상한과 함께 정량화된 여지를 남기는지 신뢰구간과 함께 분리해 낸 것.**

## 7. 선행연구와의 관계

이 저장소의 주장은 확립된 문헌 위에 서 있다. **어느 것이 재확인이고 어느 것이 새로운지**를 먼저 밝힌다.

### 7.1 LoRa ML 검출기의 최적성 — §4.2 논증의 토대 (재확인이다)

Vangelista [1] 는 LoRa 를 frequency shift chirp modulation (FSCM) 으로 정식화하고, **AWGN 하 최적(ML) 수신기가 de-chirp 후 DFT 로 정확히 구현된다**는 것을 유도했다. §4.2 의 "프로토타입 상관 `{|p_m^H y|}` 가 충분통계량"이라는 논증은 이 결과의 재진술이며, 새로운 주장이 아니다. 본 저장소의 기여는 그 정리를 **이 구현에 적용해 1차 결론을 반증한 것**이지 정리 자체가 아니다.

Chiani & Elzanaty [2] 는 LoRa 파형 간 상호상관을 닫힌 형태로 구해 **심볼 수 M 이 클 때에만 근사 직교**임을 보였다. §4.1 에서 측정한 `|cos| ≈ 0.0035` (SF9, M=512) 는 이 결과의 수치적 확인이다. 따라서 "직교 codebook 위에서는 거리 기반 군집(SOM)이 SNR 과 무관하게 실패한다"는 §4.1 의 철회 논증은 **알려진 성질로부터의 따름정리**이며, 독립적 기여로 내세울 수 없다.

Elshabrawy & Robert [3] 의 BER 닫힌 형태 근사는 §3 의 ML 정확도 곡선을 이론값과 대조할 기준을 준다.

### 7.2 표본화율과 de-chirp 위상 정렬 — §3.4 folding 문제의 직접적 선행연구

Pasolini [4] 는 LoRa 신호 특성이 송수신기 구조에 주는 영향을 분석하면서, **수신단 표본화 주파수의 선택이 복조 유효성을 좌우하며 그 선택이 의도적으로 표본화 정리를 만족시키지 않는다**는 점을 다룬다. 이것이 §3.4 에서 측정한 현상의 문헌상 대응물이다. 표준 LoRa 수신기가 `fs = BW` 에서 도는 것은 우연이 아니라, **그 표본화율에서만 de-chirp 후 두 톤이 같은 bin 에 결맞게 겹치기 때문**이다. OSF>1 에서 같은 알고리즘을 그대로 쓰면 그 결맞음이 깨진다 — 본 저장소가 밟은 함정이 정확히 이것이다.

Bernier 등 [5] 은 명시적으로 "minimum sampling rate optimum receivers" 맥락에서 타이밍·주파수 동기를 다루고, 연속 심볼 간 위상 회전으로 fractional CFO 를 추정한다. Xhonneux 등 [6] 은 표본 시간 오프셋(STO)에 강인한 저복잡도 동기를 제시한다. 두 연구 모두 **최소 표본화율이 최적성의 전제**라는 같은 구조 위에 있다.

Xu 등 [7] 은 공개 LoRa PHY 구현들의 성능 격차의 근본 원인을 규명하고, 해석적 보증과 함께 **-20 dB 에서 동작하는 복조**를 제시했다. §3 에서 발견한 "이 저장소의 baseline 이 구현 손실로 수 dB 를 버리고 있었다"는 사실은 **문제의 종류로는 [7] 이 이미 다룬 것**이다. 따라서 §3 의 기여는 "새로운 검출기"가 아니라 (i) OSF>1 에서 어떤 결합기가 얼마를 잃는지를 해석적으로 분해한 것, (ii) 그 분해가 신경망 이득의 해석을 뒤집는다는 점이다. **§3 을 단독 논문 소재로 쓸 수 없는 이유가 여기 있다.**

### 7.3 저SNR·임페어먼트 하 신경망 복조 — §5–§6 이 겨냥하는 지점

O'Shea & Hoydis [8], Dörner 등 [9] 이 물리계층을 학습으로 대체하는 프레이밍을 세웠다.

LoRa 에 직접 해당하는 것은 NELoRa [10] 다. 스펙트로그램 마스킹 denoiser 와 적응 디코더를 이어 붙인 dual-DNN 으로 **표준 LoRa 디코더 대비 1.84–2.35 dB 의 SNR 이득**을 보고했다 (SenSys'21 Best Paper). 후속 벤치마크 [11] 가 데이터셋을 공개했다. 본 저장소가 처음 시도한 것이 정확히 이 설정이었다.

§4.2 의 정리는 "AWGN·심볼 단위에서 여지는 0"이라고 말한다. NELoRa 의 보고와 모순처럼 보이지만, 모순이 아니다. 갈라지는 지점이 셋 있다.

1. **기준선.** §3 은 LoRa 디코더 구현이 최적 대비 수 dB 를 잃을 수 있음을 보인다. 표준 디코더를 기준선으로 잰 이득은 **그 구현 손실을 되찾은 몫과 분리되지 않는다.** 본 저장소의 1차 결과(+9%p)가 정확히 그 경우였다 (§3.2). 학습 기반 복조 논문이 기준선의 최적성을 함께 보고해야 하는 이유다.
2. **채널.** NELoRa 는 실측 신호를 쓰므로 CFO·SFO·하드웨어 임페어먼트가 들어 있고, §4.2 의 정리는 AWGN 에만 적용된다. 즉 그 이득이 실재한다면 원천은 denoising 이 아니라 임페어먼트 보상일 가능성이 크다 — 이것이 이 저장소가 세웠던 가설이다.

   → **측정 결과 다른 답이 나왔다([`NELORA.md`](NELORA.md)).** 원천은 임페어먼트 보상이 아니라 **대역 밖 잡음**이었다. 정렬(타이밍/CFO 보정)을 아무에게도 주지 않은 조건에서 이미 격차가 나타나고, 모든 팔에 ±BW/2 대역제한 입력을 주면 그 격차가 +3.33 → +0.28 dB [−0.14, +0.70] 로 사라진다. 신경망에 같은 대역제한 입력을 주면 자기 baseline 보다 0.53 dB 뒤진다 — 벌던 이득이 그 몫이었다는 뜻이다. 정렬된 경험적 정합필터(상한)에는 1.53 dB 못 미친다.
3. ~~**보고된 이득의 견고성 자체가 아직 독립 확인되지 않았다.**~~ → **닫았다([`NELORA.md`](NELORA.md)).** 공개 벤치마크 [11] 의 데이터와 코드로 재현했다. 그들 `test()` 를 무수정 실행한 값과 하네스가 네 지점 0.1 dB 이내로 일치하고, 그들 코드로 재학습한 신경망이 held-out 패킷에서 +1.36 dB 를 얻어 발표 수치(+1.46) 수준에 도달한다. **그 위에서 같은 배치로 비교하면 데시메이션을 넣은 고전 수신기가 +3.32 dB 를 얻는다.** 추정이 아니라 재현으로 닫은 항목이다.

시변 CFO/SFO 자체는 알려진 문제이고, preamble 기반 추정·보상이 표준적 대응이다 [5,6,7]. 본 연구가 §5.3–§5.6 에서 더하는 것은 그 조건에서 **계산 가능한 상한(genie)과 함께** 남는 여지를 초저 SNR 구간에서 정량화하고, **baseline 을 blind → 상수-CFO → drift-aware 2D 로 단계적으로 올리면서** 어느 단계에서 무엇이 닫히고 무엇이 남는지를 대응표본 신뢰구간과 함께 분리해 내는 것이다. 특히 상수-CFO 추정기만 놓고 "고전 방법이 실패한다"고 말하면 허수아비가 된다는 점을 스스로 확인하고, 그 baseline 을 올린 뒤에도 남는 구간만을 열린 조건으로 주장한다.

| 소재 | 주장 | 재검증 후 상태 |
|---|---|---|
| §3.2–§3.4 (검출기, +39.6%p) | 특정 구현의 검출기 결함과 그 해석적 분해 | **단독 불가.** 표본화율 문제는 Pasolini [4] 가, 공개 구현의 성능 격차는 Xu 등 [7] 이 이미 다뤘다. 독립 재현과 결합기별 손실 분해(-6.02 / -1.76 / ~0 dB)는 가치가 있으나 새 기여로 서지 않는다. |
| §4.1–§4.2 (SOM 반증 + 정리) | 직교 codebook 에 거리 기반 방법은 부적합 | **단독 불가.** Vangelista [1] 의 최적성과 Chiani & Elzanaty [2] 의 준직교성에서 나오는 따름정리다. |
| §5.3–§5.6 (CFO 여지 지도) | 고전 CFO 추정기가 **어디서** 멈추는지를 상한과 함께 정량화 | **가능하다.** 그리고 이번 재검증으로 주장이 하나 늘고 하나 줄었다. |

### 왜 §5 인가

folding 이슈와 무관하다. §3 의 어떤 정정도 §5 의 수치를 건드리지 않는다 — §5 는 처음부터
ML(= matched filter) 을 기준으로 재고 있었기 때문이다. 그리고 baseline 사다리를 세 단계
(blind → 상수-CFO 1D → drift-aware 2D) 로 올린 뒤에도 닫히지 않는 구간이 남았다.

**기여 1 — 정적 CFO 라도 깊은 SNR 에서는 고전 패킷 추정기가 상한에 못 닿는다 (§5.3).**
이전 판은 "-28 dB 까지 고전 grid search 가 genie 와 사실상 같다"고 적었다 (1024 심볼, CI 없음).
패킷 수를 늘리고 CI 를 붙이자 -32 ~ -26 dB 전 구간에서 격차가 유의해졌고, grid 를
0.125 → 0.03125 bin 으로 줄여도 그대로 남는다. **양자화 잔차가 아니라 추정 실패다.**

**기여 2 — 시변 CFO 는 "모델이 맞느냐"로 갈린다 (§5.5–§5.6).**
이것이 이번 재검증의 핵심이고, 논문의 중심 주장이 되어야 한다.
- 상수-CFO 추정기는 drift 1 bin 에서 blind 보다 **나빠진다** (-2.66%p [-3.61, -1.70]).
- 그러나 그것만으로 "고전 방법이 실패한다"고 쓰면 허수아비다. offset × 기울기 2D 탐색이라는
  자연스러운 확장을 쓰면 **선형 drift 는 전 구간에서 닫힌다** (drift 2 bin 에서도 genie 와
  1.83%p [0.70, 3.21] 차이).
- 반면 drift 가 심볼 단위 random walk 면 2D 탐색도 무력해진다. 기울기 차원을 더해도
  얻는 것이 없고(p=0.17 / p=0.15), 변화폭 1 bin 에서 **22.0%p**, 2 bin 에서 **34.8%p** 가
  상한과 함께 남는다.

즉 논문이 지정하는 것은 "CFO 가 있으면 여지가 있다"가 아니라
**"CFO 의 시간 변화가 저차 파라메트릭 모델로 기술되지 않을 때에만 여지가 있다"** 이다.
이 경계선이 새롭고, 신뢰구간과 상한이 함께 붙어 있어 검증 가능하다.

### 논문 형태 제안

- **제목(가안):** *Where classical CFO estimation stops paying: a genie-bounded headroom map for
  ultra-low-SNR LoRa demodulation*
- **주 기여:** 초저 SNR × CFO 조건에서 blind / per-symbol joint / packet-constant / drift-aware 2D
  네 baseline 이 **계산 가능한 genie 상한 대비 어디서 멈추는지**를 대응표본 신뢰구간과 함께 지도화.
  학습 기반 복조가 겨냥해야 할 구역을 수치로 지정한다.
- **부 기여 (방법론 경고):** §3 을 여기에 넣는다. 표준 LoRa 디코더 구현이 OSF>1 에서 4.2 dB 를
  잃을 수 있고, 그 손실은 학습 기반 복조가 보고하는 SNR 이득과 **분리되지 않는다.** 본 저장소의
  1차 결과(+9%p)가 실제로 그 경우였다. 이 절이 §3 을 낭비하지 않고 쓰는 유일한 방법이다.
- **하지 말 것:** "신경망이 고전 방식을 이겼다"는 주장. 이 저장소에는 그 실험이 없다.
  낼 수 있는 것은 **여지의 지도**이지 그 여지를 채웠다는 결과가 아니다.

### 내기 전에 보강해야 할 것

**이번 genie 감사(§5.7)로 닫힌 것.** 이전 판의 목록에서 네 항목이 to-do 를 벗어났다.

- **상한의 정당성** (이전 6번). "genie ≥ 임의의 CFO-비인지 수신기"를 진술만 하는 것이 아니라,
  side info 없는 모델 인지 추적기가 정적 CFO 에서 0.08%p (p=0.36), 선형 drift 2 bin 에서
  0.90%p 까지 **실제로 상한에 닿는 것**을 보였다. 상한이 느슨해서 생긴 격차가 아니다.
- **메커니즘의 특정.** 남는 격차의 원인이 ε 의 정수부와 데이터 심볼의 교락이고, 그 손실이
  **P(n≠0) × p_genie** 를 정확히 따른다. 열린 조건을 "저차 모델로 기술되지 않는 시변 CFO"
  보다 좁게 — **정수-bin 횡단이 예측되지 않는 시변 CFO** 로 — 특정할 수 있다.
- **해상도 가설 배제.** 블록-genie 스윕이 8 심볼 블록평균에서 50.3% 를 내므로, genie 가
  물리적으로 불가능한 시간 해상도를 요구한다는 반론은 성립하지 않는다.
- **여지 수치의 갱신.** genie − 2D 가 아니라 genie − 추적기 기준으로 22.1%p / 32.1%p.

**남은 것, 우선순위 순.**

1. **ns=512 에서 헤드라인 재설정.** 물리 단위 환산은 끝났다 — 868 MHz · ns=128 에서
   **1 bin = 0.56 ppm = 2.15 ppm/s**, ns=512 면 **0.54 ppm/s** 다. ns 가 지렛대이므로 헤드라인
   행을 ns=512 에서 다시 잡을 여지가 있다. 단 **random walk 는 스펙이 달라 같은 방식으로
   환산하면 안 된다** — 램프가 아니므로 ppm/s 라는 양이 정의되지 않는다.
   **σ_y(τ = 2.05 ms) ≈ 5e-8** (Allan deviation) 으로 표기하고, 선형 drift 와 같은 근거로
   정당화하지 않는다.
2. **실측 데이터 재현.** NELoRa-Bench [11] 공개 데이터셋에서 같은 baseline 사다리를 돌린다.
   §7.3 의 세 번째 갈래(보고된 이득의 견고성)를 닫을 수 있는 **유일한** 방법이므로, 이전 판의
   "향후 과제" 지위에서 올라왔다.
3. **drift 모델의 정당화.** random walk 는 여전히 발진기 위상잡음의 편의적 대리모형이지
   측정된 모형이 아니다. 다만 §5.7 이 메커니즘을 **정수-bin 횡단률 P(n≠0)** 하나로 좁혔으므로,
   실측 궤적에서 그 횡단률만 재면 된다. Allan variance 기반 모형으로 바꾸는 작업이 여기 붙는다.
4. **SF 다양화.** 지금 전부 SF9 단일이다. 최소 SF7 · SF10 · SF12 에서 같은 지도를 재생산해야 한다.
5. **coded FER.** 심볼 정확도만으로는 시스템 주장이 약하다. Hamming/interleaving 을 태운
   프레임 오류율로도 같은 결론이 나오는지 확인한다 [7].

## 폴더 구성

폴더는 **실험 시간 순**으로 번호가 매겨져 있으며, 이름에 그 시점의 접근이 드러난다.
`01 → 07` 순서로 읽으면 §3.1 까지의 실제 코드 궤적을, `verification/` 은 §3.2 이후 재검증의 궤적을 따라갈 수 있다.

```
LoRa-bam-reconstruction/
├── utils/                                 # 공용: LoRa 클래스, BAM 구현, 심볼 추정
├── 01_baseline_stft-magnitude-bam/        # STFT magnitude(dB) + MultiBAM
├── 02_bam-v3_complex-spectrogram/         # Complex 스펙트로그램 + MultiBAMv3
├── 03_bam-v4_tied-autoencoder/            # Tied AE 구조
├── 04_bam-v5_untied-residual-huber/       # Untied + outer residual + Huber
├── 05_bam-v6_residual-fc-blocks/          # Residual FC block 스택
├── 06_bam_complex-iq-direct/              # 단층 Complex-Valued BAM (IQ 직접 입력)
├── 07_noise2noise/                        # Noise2Noise 학습 (1차 결과)
├── verification/                          # 재검증 — 1차 결론 반증 + CFO headroom 측정
├── simulation_theory/                     # 복소수 활성함수(modReLU, zReLU) 시각화
└── local/                                 # README용 결과 이미지
```

공통 설정: SF = 9 (심볼 512개), fs = 1 MHz, 노이즈는 AWGN.

### 01_baseline_stft-magnitude-bam/ — 실수 도메인 baseline
- IQ → STFT → BW crop → **magnitude(dB) / magnitude flatten** 위에서 BAM 학습.
- 결과: 모든 SNR에서 baseline과 동률 또는 낮음. Complex 정보 소실이 원인으로 추정 → 다음 폴더에서 complex 도메인으로 이동.

### 02_bam-v3_complex-spectrogram/ — Complex 스펙트로그램 진입
- Complex STFT (real/imag concat 7936-dim) + `MultiBAMv3` (Torch, identity 활성, target-driven W 갱신, weight decay + grad clip).
- BW = 250 kHz, OSF = 4.
- **출력 collapse 관측** — 입력이 달라져도 출력이 상수 근처로 수렴, 정답률 0.0~0.4%.

### 03_bam-v4_tied-autoencoder/ — Tied AE로 재파라미터화
- `W_dec = W_enc^T` 로 묶고 leaky_relu + MSE + Adam.
- 같은 collapse 재현. **단일 심볼 디버깅에서 복원 peak이 clean 대비 0.2% 수준** → 진폭 붕괴가 학습 목적함수 수준의 문제임을 확인.

### 04_bam-v5_untied-residual-huber/ — Outer residual + Huber
- `x + α·δ` outer residual과 Huber loss로 collapse 방지.
- collapse는 해결. 그러나 모든 SNR에서 baseline보다 낮음 (예: -20 dB baseline 99.4% vs BAM 74.1%).

### 05_bam-v6_residual-fc-blocks/ — 깊이 확장
- Encoder/decoder를 `ResidualFCBlock` 스택으로 확장, `residual_alpha` epoch 스케줄.
- baseline과 거의 동률. 깊이만 늘려서는 개선되지 않음이 확인됨 → **여기서 "구조 실험" 라인 중단.**

## 부록 — 핵심 함수

원본 디코딩 코드에는 `power[:2^sf]` 로 앞 bin만 잘라 보는 오류가 있어 **OSF>1일 때 FFT power의 OSF-fold 합산이 누락**되어 있었다. 아래 함수는 이를 수정한 것으로, 01~07 모든 실험의 baseline·평가 파이프라인이 이 함수를 공유한다.

> **다만 이 수정 자체는 최적 detector가 아니다.** §3.3 에서 측정했듯 이 파이프라인의 dechirp+FFT는 심볼 에너지를 단일 bin에 모으지 못한다. dechirp된 심볼은 겹치지 않는 두 시간 구간이고, 2048-point FFT에서 bin `m` 과 bin `m+1536` 으로 갈라진다. OSF-fold는 그 두 조각을 non-coherent하게 합칠 뿐이며, **복소합으로 바꾸면 오히려 6 dB 더 나빠진다**(대역제한 없는 데시메이션이 되므로). 최적 검출기는 512개 프로토타입과의 상관(noncoherent matched filter)이고, 격차는 SNR 환산 **평균 4.2 dB** 다(§3.3 (c)). 같은 값을 `fs = BW` 로 **대역제한 후 데시메이션**하고 512-point dechirp+FFT를 쓰면 손실 없이 얻는다. **01~07 의 모든 정확도 수치는 이 ≈4.2 dB suboptimal baseline 기준으로 읽어야 한다.**
